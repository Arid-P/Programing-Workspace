# 💻 Ari's Programming Workspace

Welcome to my primary programming workspace! This repository is a centralized hub for my algorithmic problem-solving, data structure practice, and standalone utility scripts. 

## 📂 Repository Structure

*   **`Leetcode/`**: Tracked solutions, version iterations, and stress tests for LeetCode problems (e.g., *Two Sum*, *Best Time to Buy and Sell Stock*, *Remove Duplicates*).
*   **`data_structure_algorithm/`**: Core DSA concepts and challenge solutions from platforms like HackerRank (focusing heavily on array manipulation).
*   **`random/`**: Standalone Python scripts for various tasks, including data parsing (`prase.py`), graph rendering (`graph.py`), quantum orbital visualizations (`orbitals.py`), and IOQM prep notes.
*   **`Theory/`**: Reference materials, notes, and command-line mastery documentation.
*   **`Python/` & `Others/`**: General Python experimentation and miscellaneous coursework scripts.

> **Note:** My main Flask web application project, **FluxDone**, is isolated and maintained in its own dedicated repository to keep this workspace clean.

## 🛠️ Tech Stack & Environment

*   **Mobile Development Setup:** Termux + Acode
*   **Version Control:** Git & GitHub
